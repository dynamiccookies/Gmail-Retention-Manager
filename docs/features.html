Features

Focused tools for practical email retention.

Manage recurring expiration without turning Gmail into a separate records-management system.

Flexible policies

Use minutes, hours, days, weeks, calendar months, or calendar years. Policies are expressed directly in Gmail label names and can be applied manually or by filters.

Gmail sidebar

See schedule status, last and next runs, current runtime state, and basic settings from Gmail. Start an immediate background scan without waiting on the card.

Administration page

Configure labels, schedules, notifications, backups, filter cleanup, and diagnostic settings from a responsive private web interface.

Deletion reporting

Receive a summary of moved messages with direct links to the affected Gmail conversations. Large reports and interrupted delivery can be recovered.

Runtime safeguards

Preflight checks, lock handling, progress checkpoints, and recorded run state help prevent overlapping scans and make failures easier to understand.

Filter cleanup

Review suggestions for combining simple Gmail filters that perform only the same retention-label action. Nothing is merged without confirmation.

Settings backups

Create, restore, import, and export validated configuration backups before making significant changes.

Update awareness

Optional release checks compare the installed version with public GitHub releases and direct the administrator to release details.

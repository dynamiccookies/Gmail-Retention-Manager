Privacy

Your mailbox stays in your Google account.

This page describes the current manually installed, open-source version of Retention Manager for Gmail™.

Last updated: September 3, 2026

How the application runs

The manual version is copied into and executed from a Google Apps Script project owned by the installing user. Its Gmail operations run under that user’s authorization.

Information the application accesses

The application accesses Gmail labels, conversations, messages, filters, and the installing account’s email address as needed to evaluate retention policies, move eligible messages to Trash, manage requested filters, and send operational notifications.

Information stored

Configuration, schedules, runtime status, backups, and recovery checkpoints are stored in Apps Script services associated with the user’s installation. They are used to operate and recover that installation.

External requests

When update checks are enabled, the application requests public release information from GitHub. Mailbox content and Gmail metadata are not included in that request.

Data sharing

The project does not sell user information. The current application code does not transmit mailbox content to the project maintainer or to an application-operated server.

Website data

This website is hosted by GitHub Pages. GitHub may process visitor information, including IP addresses, under GitHub’s own privacy terms. This site does not currently use a separate analytics service, advertising network, account system, or contact form.

Data removal

Users can remove the Apps Script project and revoke its Google account access. See the updating and uninstalling guide.

Scope of this notice

A future Google Workspace Marketplace edition may use a different deployment model and will require an updated privacy notice before publication.

Questions

Use the project’s GitHub issue tracker for privacy questions. Do not post email content, addresses, subjects, message identifiers, or access tokens publicly.
